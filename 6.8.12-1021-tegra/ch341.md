# 6.8.12-1021-tegra

* Jetson Linux 39.2
* NVIDIA JetPack 7.2

## CH341

### Verify that the CH341 driver is not installed

```
$ sudo modprobe ch341
modprobe: FATAL: Module ch341 not found in directory /lib/modules/6.8.12-1021-tegra
```

### Verify that ch341.ko is compatible with the running kernel

```
$ uname -r
6.8.12-1021-tegra
$ modinfo ./ch341.ko
filename:       /home/jetson/./ch341.ko
license:        GPL v2
alias:          usb:v9986p7523d*dc*dsc*dp*ic*isc*ip*in*
alias:          usb:v4348p5523d*dc*dsc*dp*ic*isc*ip*in*
```

### Install ch341.ko

```
$ sudo install -D -m 0644 ./ch341.ko "/lib/modules/$(uname -r)/updates/ch341.ko"
$ sudo depmod -a
$ sudo modprobe ch341
```
